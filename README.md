# Meu Diário — PWA

## Publicar no Netlify

1. Envie todos os arquivos desta pasta para a raiz do repositório no GitHub.
2. No Netlify, conecte o repositório. O `netlify.toml` publica a raiz sem comando de build.
3. Abra o endereço HTTPS do Netlify no celular. A instalação e o service worker exigem HTTPS (ou `localhost`).
4. Toque em **INSTALAR** quando o navegador apresentar a opção. Se não aparecer, abra o menu do navegador e escolha **Instalar aplicativo** ou **Adicionar à tela inicial**.
5. No iPhone/iPad, use o Safari: **Compartilhar → Adicionar à Tela de Início**.

Depois de instalado, abra pelo ícone da tela inicial e toque em **ENTRAR**. O botão tenta chamar o aviso de instalação do navegador quando ele está disponível. O app guarda dados no armazenamento local deste navegador/dispositivo; use as opções de backup do próprio app para exportar e importar dados. O conteúdo não é sincronizado automaticamente entre aparelhos.

A abertura do app instalado deve ser feita pelo ícone adicionado à tela inicial. Uma aba comum do site não pode forçar a troca para o app instalado.
